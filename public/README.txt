HOW TO INSTALL AND RUN:

OPTION 1 (Recommended - 1-Click Installer):
1. Double-click "Install-Sunfyer.bat".
2. It will install Sunfyer into your Windows system and place a 
   shortcut with the custom Sunfyer icon on your Desktop and Start Menu.
3. Sunfyer will launch in dedicated Windows App mode!

OPTION 2 (Direct Standalone Executable):
1. Double-click "Sunfyer.exe".
2. If Windows SmartScreen asks for confirmation (since it is a custom app),
   click "More info" -> "Run anyway".
3. Sunfyer will launch immediately.

TO UPDATE IN THE FUTURE:
- Run "Update-Sunfyer.bat" to automatically download and verify the latest build,
  or use the in-app update button inside Sunfyer.
